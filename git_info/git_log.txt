Author: Muyi Lin <muyi.lin@hpe.com>
Date:   Sun May 31 13:55:44 2026 -0700

    feat: integrate SINDYc learned dynamics into Lyapunov-guided diffusion controller
    
    Implements the data-driven regime from our AAAI draft (Theorem 6):
    the CLBF and diffusion sampler are trained against an estimated
    dynamics model f_hat learned via SINDYc, rather than requiring
    known physics equations.
    
    New files:
    - sindy/collect_data.py: safe data collection using LQR + noise
    - sindy/identify_dynamics.py: PySINDy STLSQ identification
    - sindy/evaluate.py: evaluation on true dynamics with Theorem 6 plots
    - systems/sindy_estimated_system.py: drop-in surrogate dynamics class
    - training/train_inverted_pendulum_sindy.py: training with learned dynamics
    - run_sindy_pipeline.sh: end-to-end pipeline script
    
    Compatibility fixes for PyTorch Lightning 2.x and optional deps.
